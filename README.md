# Jogo de Campo Minado para Terminal



---



O jogo simples do Campo Minado para jogar em terminal. Durante a execução, siga atentamente às instruções deixadas para uma experiência completa!



Exemplo de jogo:



        01 02 03 04 05 06 07 08 09 

    01  0  0  0  1  #  #  #  #  # 

    02  0  0  0  1  P  #  #  #  # 

    03  1  1  1  1  #  #  #  #  # 

    04  #  #  #  #  #  #  #  #  # 

    05  #  #  #  #  #  #  #  #  # 

    06  #  #  #  #  #  #  #  #  # 

    07  #  #  #  #  #  #  #  #  # 

    08  #  #  #  #  #  #  #  #  # 

    09  #  #  #  #  #  #  #  #  # 



Tabuleiro \[9x9]



Revelar: \[1]

Marcar/desmarcar: \[2]

Sair do jogo: \[-1]

Dar lance: acao \[1, 2 ou -1]) e (coordenadas \[x, y]



---

"#" => Célula escondida

"0 a 8" => Célula revelada exibindo o número de bombas adjacentes a ela

"P" => Bandeira

"\*" => Bomba (todas são exibidas ao perder o jogo)



---

DAR LANCE:

Lance digitado pelo usuário:

        1 1 4
---
Significa: "Realize a ação de REVELAR na célula da LINHA 1 e da COLUNA 4"

---



Caso fosse:

        2 1 4 

---
Significa: "Realize a ação de MARCAR/DESMARCAR na célula da LINHA 1 e da COLUNA 4"

---



---

\[BÔNUS]



Algumas células que não possuem bombas vão revelar automaticamente com uma bandeira. Quanto maior a dificuldade, mais células bônus aparecerão em campo.




---

RECORDES E RANKING



Ao ganhar um jogo de dificuldade nível 4, você salva seu recorde de tempo e pode se registrar em uma classificação geral contendo os 10 melhores jogos. Quanto mais rápido você o fizer, mais no topo você ficará!



---

APELIDOS



Antes de iniciar um jogo, crie ou faça o login de um usuário que ficará salvo na memória rígida após o registro. Cada nome ou apelido é único! Lembre-se também da sua senha se quiser entrar mais tarde para jogar!
